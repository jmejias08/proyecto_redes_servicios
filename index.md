### Descripcion del Proyecto:
Este proyecto consiste en la implementación de una red corporativa virtualizada que incluye diversos servicios de red y sistemas. La topología se basa en un dispositivo MikroTik como router principal (RouterCore), conectado a una máquina servidor Linux y clientes Windows.

### Objetivos del Proyecto:
- Router MikroTik como núcleo de la red
- Servidor Ubuntu con Docker para servicios
- Servicios de red: DNS (AdGuard Home), VPN (Tailscale) y monitoreo (Uptime Kuma)
- Cliente Windows para validar el funcionamiento de los servicios
